Seurat V5 - Find differentially expressed genes between clusters

Description

When provided with a Visium HD Seurat object with cluster information, this tool finds differentially expressed genes (DEGs) between two clusters and visualizes them on top of the tissue histology.

Parameters

  • Assay to use [Spatial.008um]
  • Was sketch clustering used for 8 bin assay [yes]
  • First cluster [1]
  • Second cluster [2]
  • Limit testing to genes which are expressed in at least this fraction of spots [0.25]
  • Limit testing to genes which show at least this fold difference [0.1]
  • Test for differential expression (wilcox, MAST)[wilcox]
  • Report only positive marker genes [yes]
  • Determine color scale based on all genes [no]
  • Width of the output plot [10]
  • Height of the output plot [10]

Details

This tool identifies DEGs between the clusters of interest. If you set the parameter value for "Report only positive marker genes" to "yes", only genes with positive fold change will be listed. You can also select the test used for differential expression testing using the parameter "Test for differential expression" from two options: Wilcoxon Rank Sum Test (wilcox) or the hurdle model tailored to scRNA-seq analysis called MAST.

In order to speed up the statistical testing, you can filter out genes prior to testing by requiring that a gene has to be expressed in at least a certain fraction of spots in either of the two clusters. You can also filter out genes whose log2 fold change between the two clusters is less than a given value.

This tool lists the discovered DEGs and visualizes them on tissue image. By default, the color scale is determined for each gene individually and may differ between genes. If you wish to compare expression between different genes, it may be useful to set the parameter value for "Determine color scale based on all genes" to "yes" so that the color scale is the same for all genes.

Output

  • Markerplot.pdf: A plot of the identified top marker genes
  • spatially_variable_genes.tsv: A table of the differentially expressed genes
