Seurat v5 -Find differentially expressed genes between clusters

Description

This tool finds differentially expressed genes (DEGs) between two clusters and visualizes them on top of the tissue histology. To find genes whose expression follows the spatial location without clusters, use the tool "Seurat v5 -Identify spatially variable genes without pre-annotation".

As an input, you can provide the Seurat object after the "Seurat v5 -Clustering" step.

Parameters

  • First cluster [1]
  • Second cluster [2]
  • Limit testing to genes which are expressed in at least this fraction of spots [0.01]
  • Limit testing to genes which show at least this fold difference [0.1]
  • Test for differential expression [wilcox]
  • Report only positive marker genes [FALSE]
  • Number of differentially expressed genes to visualize [3]
  • Determine color scale based on all genes [no]

Details

The user can select the clusters where differentially expressed genes would like to be identified. The cluster numbers are the ones in the plots of the "Seurat v5 -Clustering" tool, and the numbering starts from 0. The tool identifies positive and negative marker genes for the clusters of interest, determined by the user. You can choose to return only positive marker genes by selecting "TRUE" as the parameter value for "Report only positive marker genes". You can also select the test used for differential expression testing using the parameter "Test for differential expression" from two options: Wilcoxon Rank Sum Test (wilcox) or the hurdle model tailored to scRNA-seq analysis called MAST.

The genes are ordered by p-value, and the plot shows the top genes of this list. With the default value "FALSE" of "Report only positive marker genes", these can also be negative markers, i.e. genes with lower expression in the first cluster than in the second one (a negative avg_log2FC in the result table). Set the parameter to "TRUE" to plot only genes with higher expression in the first cluster.

If the samples have been combined with "Seurat v5 -Combine multiple samples, normalization and PCA", the tool first recorrects the normalized expression values of all samples to the same sequencing depth (the smallest of the samples' median UMI counts), so that the samples can be compared. The plotted expression values may therefore differ slightly from the ones in the earlier tools.

The user can also filter out genes prior to statistical testing by requiring that a gene has to be expressed in at least a certain fraction of spots in either of the two clusters using the parameter "Limit testing to genes which are expressed in at least this fraction of spots". You can also filter out genes whose log2 fold change between the two clusters is less than a given value using the parameter "Limit testing to genes which show at least this fold difference". Both of these parameters can be set to 0, but with a significant increase in computation time since this will test a large number of genes that are unlikely to be highly expressed.

This tool finally visualizes and lists the discovered DEGs between clusters. By default, the color scale is determined for each gene individually and may differ between genes. If you wish to compare expression between different genes, it may be useful to set the parameter value for "Determine color scale based on all genes" to "yes" so that the color scale is the same for all genes.

For more details on the spatial transcriptomics analysis pipeline, please check the Seurat tutorial.

Output

  • Markerplot.pdf: The top differentially expressed genes plotted on top of the tissue image.
  • spatially_variable_genes.tsv: The differentially expressed genes between the two clusters with their p-values, log2 fold changes and the fractions of spots where the gene is detected in each cluster (pct.1 and pct.2).
