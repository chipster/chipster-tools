Seurat v5 -Cluster visualisation

Description

This tool visualizes existing cluster assignments in tSNE and UMAP plots. It is intended for use after the Seurat v5 -Clustering tool, which performs the clustering and computes the dimensionality reductions. Use this tool when you want to regenerate or customise the cluster plots without rerunning the full clustering step.

Parameters

  • Point size in tSNE and UMAP plots [1]
  • Add labels on top of clusters in plots [yes]
  • Which dimensionality reductions to plot [UMAP and tSNE]

Details

This tool takes as input a Seurat R-object that already contains cluster assignments and pre-computed dimensionality reductions (UMAP and/or tSNE). Both are produced by the Seurat v5 -Clustering tool.

The point size parameter controls the size of individual cells in the plots. For datasets with many cells, a smaller point size (e.g. 0.3–0.5) can make the plot easier to read by reducing overplotting.

The Add labels option places the cluster number at the centroid of each cluster directly on the plot. This is convenient for quick inspection. If the labels overlap or obscure the data, switch this off and rely on the colour legend instead.

The Which dimensionality reductions to plot parameter lets you request UMAP only, tSNE only, or both. If a requested reduction is not present in the Seurat object, that plot will be skipped and a warning will be written to the log. The tool will stop with an informative error if neither UMAP nor tSNE is available in the object.

A summary table showing the number of cells in each cluster is included as the last page of the PDF.

For more details on the clustering itself and how the dimensionality reductions are computed, please see the manual page of the Seurat v5 -Clustering tool and the Seurat tutorials.

Output

  • clusterPlot.pdf: Cluster visualisation in UMAP and/or tSNE plots, followed by a table showing the number of cells per cluster per sample.
