Seurat v5 -Plot clusters

Description

When provided with a Visium HD Seurat object with cluster information, this tool visualizes clusters on a UMAP plot and on their spatial location. This allows you to plot clusters with new cluster names, if you have annotated the clusters.

Parameters

None

Details

The tool produces two plots per assay, colored by cluster.
  • UMAP plot shows the clustering results on a 2D scatterplot where each point is a bin positioned based on its UMAP embedding. When sketch-based clustering is used, the UMAP shown is the projection of all bins (not just the sketched subset).
  • spatial clustering plot shows the clusters overlaid on the tissue image.

For more details on the Visium HD analysis pipeline, please check the Seurat Visium HD vignette.

Output

  • clustering_plots.pdf: UMAP plot and spatial clustering plot for each assay.
