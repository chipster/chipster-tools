Seurat v5 -Visualize gene expression

Description

Given normalized Visium HD data, this tool visualizes the expression of selected genes on the tissue image. This allows you to observe spatial patterns of gene expression and correlate them with histological features.

You can either list your genes of interest as a comma-separated (,) list or upload a tsv file containing genes as a single column without a header

Parameters

  • Gene name ["Hpca, Ttr"]
  • Point size [1.6]
  • Minimum transparency of the points [1]
  • Maximum transparency of the points [1]
  • Determine color scale based on all genes [no]
  • Width of the plot [10]
  • Height of the plot [10]

Details

The tool generates a spatial plot for each gene, where the color intensity represents the expression level of the gene in each bin. Note that you can select whether the color scale is based on all genes or individual genes. By default, the color scale is determined for each gene individually and may differ between genes. If you wish to compare gene expression between different genes, it is useful to set this parameter to "yes" so that the color scale is the same for all genes.

For more information, please see the Seurat Visium HD vignette.

Output

  • gene_expression_plot.pdf: Spatial plot of genes' expression.
