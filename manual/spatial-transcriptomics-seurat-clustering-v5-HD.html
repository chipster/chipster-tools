Seurat v5 HD -Clustering

Description

This tool performs clustering for a single sample after the "Seurat v5 HD -Normalization and PCA" step, or for multiple samples that have been combined into one Seurat object using the tool "Seurat v5 -Combine multiple samples, normalization and PCA". This tool clusters the spots with a graph-based clustering approach and visualizes the clustering results.

The tool processes both the 8 μm and 16 μm assays. For the 8 μm assay, an optional sketch-based clustering approach is available (see Details).

Parameters

  • Dimensions of reduction to use [30]
  • Resolution for granularity for clustering [0.8]
  • Use sketch-based clustering for 8 μm assay [no]
  • Number of bins to use in sketch [50000]

Details

Spots are clustered using the low-dimensional space computed in the previous step with PCA. The user can reduce the dimensionality of the space for clustering by selecting a lower number for the "Dimensions of reduction to use" parameter. The visualizations produced in the previous step can help in selecting an appropriate dimensionality.

Graph-based clustering is performed by calculating k-nearest neighbors, constructing a shared nearest neighbor (SNN) graph, and optimizing the modularity function to determine the clusters. First, a k-nearest neighbors graph is constructed using the Euclidean distance in the PCA space. Then, the edge weights between any two spots are refined based on the shared overlap in their local neighborhoods (Jaccard distance). The graph is then cut into clusters using the Louvain algorithm. The parameter "Resolution for granularity for clustering" sets the granularity, with higher values leading to more clusters.

In order to visualize the clusters, a non-linear dimensionality reduction is performed on the clustered space using UMAP.

Sketch-based clustering for the 8 μm assay

Visium HD data at 8 μm resolution can contain several hundred thousand bins, making standard clustering slow and memory-intensive. When sketch-based clustering is enabled, a representative subset of bins is selected from the full dataset using leverage scores, clustered in memory, and the resulting cluster labels and UMAP are then projected back to all bins using the ProjectData function. This approach is recommended for large datasets and follows the Seurat v5 Visium HD vignette.

The sketch-based workflow proceeds as follows:

  1. Variable features are identified and the data is scaled on the full 8 μm assay.
  2. A sketch of the requested number of bins (default 50,000) is created using leverage-score subsampling (SketchData). Leverage scores ensure that rare and transcriptomically distinct populations are not under-represented in the sketch.
  3. Variable features, scaling, PCA, neighbor graph, clustering, and UMAP are computed on the sketch.
  4. Cluster labels and the UMAP model are projected from the sketch back to all bins (ProjectData), so that every bin in the full dataset receives a cluster label.

The 16 μm assay is always clustered using the standard method regardless of this setting.

The tool produces two plots per assay, colored by cluster:

  • UMAP plot: shows the clustering results on a 2D scatterplot where each point is a bin positioned based on its UMAP embedding. When sketch-based clustering is used, the UMAP shown is the projection of all bins (not just the sketched subset).
  • Spatial clustering plot: shows the resulting clusters overlaid on the tissue image.

For more details on the Visium HD analysis pipeline, please check the Seurat Visium HD vignette. For more details on sketch-based analysis, see the Seurat v5 sketch-based analysis vignette.

Output

  • seurat_obj_clustering.Robj: The Seurat R-object to pass to the next Seurat tool, or to import into R. You cannot open this file in Chipster but you can view the contents of the object using the Seurat v5 -Extract information from Seurat object tool.
  • clustering_plots.pdf: Contains the UMAP and spatial clustering plots for each assay.
