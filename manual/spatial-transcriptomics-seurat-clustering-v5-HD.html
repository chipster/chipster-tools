Seurat v5 -Clustering

Description

This tool performs clustering of Visium HD data after the "Seurat v5 -Normalize, find variable genes and PCA" step. Spots are clustered with a graph-based approach and the clusters are visualized with UMAP.

The tool processes both the 8 μm and 16 μm assays. The 16 μm assay is clustered using the standard method, while sketch-based clustering is used for the 8 μm assay (see Details).

Parameters

  • Number of principal components to use [30]
  • Resolution for granularity [0.8]
  • Number of bins to use in sketch for 8 μm assay [50,000]

Details

Bins are clustered using the principal components (PCs) computed in the previous step. You can reduce the dimensionality for clustering by selecting a lower number of PCs. The Elbow plot produced in the previous step can help in selecting an appropriate dimensionality.

Graph-based clustering is performed by calculating k-nearest neighbors, constructing a shared nearest neighbor (SNN) graph, and optimizing the modularity function to determine the clusters. First, a k-nearest neighbors graph is constructed using the Euclidean distance in the PCA space. Then, the edge weights between any two spots are refined based on the shared overlap in their local neighborhoods (Jaccard distance). The graph is then cut into clusters using the Louvain algorithm. The parameter "Resolution for granularity" sets the granularity for clustering, with higher values leading to more clusters.

In order to visualize the clusters, a non-linear dimensionality reduction is performed on the clustered space using UMAP.

Sketch-based clustering for the 8 μm assay

Sketch-based clustering is used for 8 μm data, which typically contains several hundred thousand bins. According to Seurat developers, sketch clustering workflow improves performance, especially for identifying rare and spatially restricted groups. In addition, it speeds up the clustering step considerably. For more information, please see the Seurat v5 Visium HD vignette.

The sketch-based workflow proceeds as follows:

  1. Variable features are identified and the data is scaled on the full 8 μm assay.
  2. A sketch of the requested number of bins (default 50,000) is created using leverage-score subsampling. The leverage-score subsampling ensures that rare and transcriptomically distinct populations are well represented in the sketch.
  3. Variable features, scaling, PCA, neighbor graph, clustering, and UMAP are computed on the sketch.
  4. Cluster labels and the UMAP model are projected from the sketch back to all bins, so that every bin in the full dataset receives a cluster label.

The tool produces two plots per assay, colored by cluster:

  • UMAP plot: shows the clustering results on a 2D scatterplot where each point is a bin positioned based on its UMAP embedding. When sketch-based clustering is used, the UMAP shown is the projection of all bins (not just the sketched subset).
  • Spatial clustering plot: shows the resulting clusters overlaid on the tissue image.

For more details on the Visium HD analysis pipeline, please check the Seurat Visium HD vignette. For more details on sketch-based analysis, see the Seurat v5 sketch-based analysis vignette.

Output

  • seurat_obj_clustering.Robj: The Seurat R-object to pass to the next Seurat tool, or to import into R. You cannot open this file in Chipster but you can view the contents of the object using the Seurat v5 -Extract information from Seurat object tool.
  • clustering_plots.pdf: Contains the UMAP and spatial clustering plots for each assay.
