Seurat v5 -DE genes between samples for a given cluster

Description

For a given cluster, this tool finds differentially expressed (DE) genes by comparing each sample against all other samples. It produces one result file per sample. This tool can be used for combined Seurat objects with 2 or more samples.

Parameters

  • Normalisation method used previously [Global scaling normalization]
  • Name of the cluster [3]
  • Return only positive marker genes [yes]
  • Fold change in log2 scale [0.25]
  • Adjusted p-value cutoff [0.05]
  • Limit testing to genes expressed in at least this fraction of cells [0.1]
  • Minimum number of cells in one of the groups [3]

Details

As input, give the combined Seurat object produced by the Seurat v5 -Integrated analysis tool. Make sure to set the Normalisation method parameter to match what was used in the earlier preprocessing step.

Select the cluster to inspect by entering its name in the Name of the cluster parameter field. By default, clusters are numbered starting from 0. The example default value is cluster "3".

For each sample, the tool uses the Seurat function FindMarkers to compare cells from that sample in the chosen cluster against cells from all other samples in the same cluster. This allows you to identify genes whose expression in a particular cluster is driven by one specific condition or sample. Conditions/samples are determined by the Sample or Group name set in the Setup tool.

You can pre-filter genes using the fold change and minimum fraction of cells parameters, both applied before the statistical test to speed up the analysis. The adjusted p-value cutoff is applied after testing: only genes meeting the threshold are kept in the output. Seurat adjusts p-values using the Bonferroni method based on the total number of genes in the dataset. This is intentional: because Seurat pre-filters genes before testing, other correction methods are not recommended.

The Minimum number of cells parameter sets a lower bound on how many cells must be present in each group for a comparison to be attempted. If either the sample being tested or the combined group of all other samples has fewer cells than this threshold in the chosen cluster, that comparison is skipped and a warning describing the cell counts is written to log.txt. The remaining comparisons still run normally. This prevents unreliable results from groups that are too small for meaningful statistics.

The result tables also include columns with the average expression of the compared groups in the chosen cluster, which makes it easier to judge the biological relevance of the fold change.

Output

One tab-separated file per sample, named de-list_samplenameVsAllOthers.tsv. The columns in each file are:

  • p_val: unadjusted p-value
  • avg_log2FC: log2 fold change of the average expression between the two groups. Positive values indicate higher expression in the sample being tested. Note that the ordering of group 1 vs group 2 follows alphabetical order of the sample names.
  • pct.1: fraction of cells in the sample being tested (group 1) that express this gene
  • pct.2: fraction of cells in all other samples (group 2) that express this gene
  • p_val_adj: Bonferroni-adjusted p-value based on the total number of genes in the dataset — use this value when filtering and reporting results
  • aver_expr_ident1: average expression in the sample being tested, within the chosen cluster
  • aver_expr_ident2: average expression in all other samples, within the chosen cluster

For more details, please check the Seurat tutorials for multiple sample analysis.
