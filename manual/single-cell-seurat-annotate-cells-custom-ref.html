Annotate cells with custom SummarizedExperiment reference using SingleR

Description

Annotate clusters and cells of a Seurat object with custom reference.

Parameters

  • Method to annotate clusters based on cell annotation [SingleR]
  • Pruning [yes]
  • Fine tuning [yes]
  • Height [10]
  • Width [10]
  • Label size[4]

Details

SingleR leverages reference transcriptomic datasets of pure cell types to infer the cell of origin of each of the single cells independently. SingleR uses the wilcoxon method for comparing gene expression. A custom reference (SummarizedExperiment object) can be used to train the SingleR model, and its annotations are combined with an unannotated Seurat object. You can make a custom reference from an annotated Seurat object in Chipster using the tool Build own reference for SingleR.

The heatmaps display the scores for all cells across all reference labels: ideally, each cell (=column) has one score that is much higher (=yellow) than the rest. Similar diagnostic can be viewed in the violion plots, where per cell "deltas" are shown. Deltas are the difference between the score for the highest label and the median across all labels for each cell.

For more details about SingleR, please check:
the SingleR GitHub repository and the SingleR Book.

Output

  • seurat_obj_custom_ref_annotated.Robj: Seurat object that has cell type annotations per cell and per cluster. The Seurat R-object to pass to the next Seurat tool, or to import to R. You cannot open this file in Chipster, but you can view the contents of the object using the Extract information from Seurat object tool.
  • SingleR_custom_ref_annotation_Plots.pdf: A UMAP showing cell type annotations on clusters and cells. Additionally, if pruning is set to yes, also plotScoreHeatmap and DeltaDistribution plots are plotted.
  • cluster_celltype_table.tsv: A tab-separated values file containing a table of cluster numbers and cell types. Numerical values represent how many cells are assigned to each cell type per cluster.
