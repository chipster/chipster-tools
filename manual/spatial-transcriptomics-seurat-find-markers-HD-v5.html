Seurat V5 - Find differentially expressed genes for each cluster

Description

This tool identifies marker genes for clusters using Visium HD data. Each cluster is compared to all the other spots. The top 5 marker genes for each cluster are visualized as a heatmap.

Parameters

  • Assay to use [Spatial.008um]
  • Was sketch clustering used for 8 bin assay [no]
  • Test for differential expression (wilcox, MAST)[wilcox]
  • Report only positive marker genes [yes]
  • Limit testing to genes which are expressed in at least this fraction of spots [0.01]
  • Limit testing to genes which show at least this fold change [0.1]
  • Label size of the plots [3]
  • Width of the plot [10]
  • Height of the plot [10]

Details

As input, give a Seurat object containing cluster information. Differentially expressed genes are by default detected using a Wilcoxon Rank Sum test. Alternatively, you can select MAST, which identifies differentially expressed genes between two groups of cells using a hurdle model tailored to scRNA-seq data. By default the tool lists only positive marker genes, in other words those genes that are more highly expressed in the cluster of interest if compared to all other spots.

In order to speed up testing, you can limit testing to genes which are detected in a minimum fraction of spots in either of the two populations. You can also limit testing to genes that show a minimum fold change between the two groups. Please note that increasing the threshold can miss weaker signals.

Output

  • markers_{assay}.tsv: A table of the identified marker genes for each cluster
  • markers_{assay}.pdf: A heatmap of the identified top marker genes
