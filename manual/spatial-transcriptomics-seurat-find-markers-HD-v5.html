Seurat Visium HD - Find all markers

Description

This tool gives you a list of all markers in your data based on clusters.

Parameters

  • Was sketch clustering used for 8 bin assay [no]
  • Assay to use [Spatial.008um]
  • Reduction to use [PCA]
  • Determine the label size of the plots [3]
  • Width of the pdf [10]
  • Height of the pdf [10]
  • Limit testing to genes which are expressed in at least this fraction of spots [0.01]
  • Limit testing to genes which show at least this fold [0.1]
  • Report only positive marker genes [no]
  • Test for differential expression [wilcox]

Details

As inputs, give a clustered Seurat object.

Finds markers (differentially expressed genes) for each of the identity classes (clusters) in a dataset. Each cluster is compared to all the other clusters.

Output

  • markers_{assay}.pdf: A heatmap of the identified top marker genes for the specified assay
  • markers_{assay}.tsv: A table of the identified marker genes for each cluster for the specified assay
