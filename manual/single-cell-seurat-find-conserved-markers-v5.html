Seurat v5 -Find conserved cluster markers in multiple samples

Description

For a given cluster, this tool finds cell type marker genes that are conserved across all conditions/samples — i.e. genes that show specific expression in that cluster regardless of the treatment or sample of origin. This tool can be used for combined Seurat objects with 2 or more samples.

Parameters

  • Normalisation method used previously [Global scaling normalization]
  • Name of the cluster [3]
  • Return only positive marker genes [yes]
  • Fold change in log2 scale [0.25]
  • Adjusted p-value cutoff [0.05]
  • Limit testing to genes expressed in at least this fraction of cells [0.1]
  • Minimum number of cells in one of the groups [3]

Details

As input, give the combined Seurat object produced by the Seurat v5 -Integrated analysis tool. Make sure to set the Normalisation method parameter to match what was used in the earlier preprocessing step.

Select the cluster to inspect by entering its name in the Name of the cluster parameter field. By default, clusters are numbered starting from 0. The example default value is cluster "3".

Conserved markers are found using the Seurat function FindConservedMarkers, which runs a differential expression test within each sample separately, comparing cells in the chosen cluster against all other cells. The script then keeps only genes where the adjusted p-value meets the cutoff in all samples — meaning the gene must show specific expression in the chosen cluster regardless of the condition or sample of origin.

You can pre-filter genes using the fold change and minimum fraction of cells parameters. Both are applied before the statistical test to speed up the analysis. Only genes that pass the adjusted p-value cutoff in all samples are kept in the final table — the tool filters on the maximum adjusted p-value across samples, so every sample must individually meet the threshold.

The Minimum number of cells parameter sets a lower bound on how many cells must be present in the chosen cluster within each sample. Increasing this value can prevent the test from running on clusters that are nearly absent in one sample, which would otherwise produce unreliable results.

Output

  • conserved_markers.tsv: A ranked list of conserved marker genes for the chosen cluster. The table has one group of columns per sample (p_val, avg_log2FC, pct.1, pct.2, p_val_adj), plus the following summary columns across all samples:
    • max.adj.p.val: the highest adjusted p-value across all samples — this is the value used for filtering
    • minimum.adj.p.val: the lowest adjusted p-value across all samples

For more details, please check the Seurat tutorials for multiple sample analysis.
