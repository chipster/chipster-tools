Seurat v5 -Combine multiple samples, normalization and PCA

Description

This tool combines multiple Seurat objects into one object, normalizes each sample with SCTransform, selects the variable genes across the samples and performs PCA. If the user selects integration as the combining method, the samples are also integrated using CCA (canonical correlation analysis).

As input, you can give two or more Seurat objects after the "Seurat v5 -Filter spots" step.

Parameters

  • Combining method [merge]
  • Number of variable genes [3000]
  • Number of PCs to compute [50]
  • Print loadings in a file [no]
  • Number of genes to list in the loadings file [5]

Details

The tool first merges the samples into one Seurat object. The samples are kept in separate layers of the object, so the normalization is still done for each sample separately.

The gene expression values are normalized using the SCTransform normalization method which uses Pearson residuals from regularized negative binomial regression, where sequencing depth is utilized as a covariate in a generalized linear model (GLM). The parameters for the model are estimated by pooling information across genes that are expressed at similar levels. This should remove the technical variation but preserve the biological heterogeneity, and avoid over-fitting the model to the data. SCTransform returns three kinds of values in the SCT assay: corrected counts and log-normalized expression values for all genes, and the Pearson residuals (scaled values) for the variable genes. The normalized values of all genes can be used in the later tools, for example for plotting gene expression.

SCTransform also detects the genes which are highly variable across spots. The tool selects the variable genes across all the samples, and you can set their number with the parameter "Number of variable genes". These genes are used for PCA and integration.

Then, this tool performs Principal Component Analysis (PCA) on the merged Seurat object with the selected variable genes. PCA is used to reduce the dimensionality of the data set (number of genes), while preserving as much variance as possible. When running PCA, you can specify the number of principal components (PCs) to compute where each PC essentially represents a 'metagene'. These components or 'metagenes' are new variables that are linear combinations of the original genes, ordered by the amount of variance they capture from the data. This means that the first principal component (PC1) captures the maximun possible variance in the data set, PC2 the second most and so on. By selecting fewer components, you can reduce the dimensionality of the data set. This makes the data easier to analyze and visualize, while still retaining the most important information. By default, 50 PCs are computed. It is important to note that selecting too few PCs may oversimplify the data, while selecting too many PCs may retain unnecessary noise.

This tool also outputs a *.txt file if the parameter "Print loadings in a file" is set to "yes". This file will list the top genes (default = 5) associated with each PC that have the largest (positive or negative) PCA loadings for each PC. PCA loadings represent the weights or coefficients of the original genes in the linear combination corresponding to each PC. Thus, PCA loadings show how much each original gene contributes to each PC component or 'metagene'.

If "integration" is selected as the "Combining method", the samples are integrated after PCA. The integration uses canonical correlation analysis (CCA) to find the shared sources of variation across the samples, and it creates a new integrated embedding called integrated.cca. Integration does not change the expression values: they are the same as with merging. The later tools, such as "Seurat v5 -Clustering", use the integrated embedding instead of PCA when the object has it, so the clusters differ between merging and integration, and so do the differentially expressed genes found between the clusters.

Integration can be used when the samples are replicates or conditions of the same tissue and there are strong batch effects between them. Don't integrate sections of different anatomical regions, for example the anterior and posterior sections of a brain. Integration then tries to align spots that are different for biological reasons, which can remove real differences between the regions (overcorrection). For such samples, choose merging.

Finally, the tool produces PCA plots which can help the user explore the primary sources of heterogeneity in the dataset, and to decide how many principal components to include for other downstream analyses:

  • Elbow plot: shows a ranking of PCs by the amount of variation explained by each PC component. It can be used to determine the primary sources of heterogeneity in the data and for selecting a cutoff of how many PCs to include for downstream analyses.
  • PCA loadings plots: show the PCA loadings for top genes associated with the first two principal components. They can be used to see which genes have the highest weights or loadings for each PC component.

For more details on the spatial transcriptomics analysis pipeline, please check the Seurat tutorial.

Output

  • seurat_obj_multiple.Robj: The Seurat R-object to pass to the next Seurat tool, or to import into R. You cannot open this file in Chipster but you can view the contents of the object using the Seurat v5 -Extract information from Seurat object tool.
  • PCAloadings.txt: If selected, this contains the top genes with largest (positive or negative) PCA loadings for each PCA component.
  • PCAplots.pdf: This contains the elbow and PCA loadings plots.
