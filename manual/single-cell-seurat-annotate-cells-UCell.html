Annotate cells with UCell

Description

UCell allows you to annotate cells/clusters with your own marker gene and cell type information.

Parameters

  • Cell types to plot [T cells, B cells, NK cells, Monocytes]
  • Gene sets for cell types [CD3D, CD3E, IL7R, sep, MS4A1, CD79A, CD79B, sep, NKG7, GNLY, PRF1, sep, CD14, LST1, S100A8]
  • Width of plots [10]
  • Height of plots [10]
  • Point size in tSNE and UMAP plots [1]
  • Label size in the output plots [4]

Details

With this tool, you can annotate cells with UCell. UCell is an R package for scoring gene signatures in single-cell datasets. UCell scores, based on the Mann-Whitney U statistic, are robust to dataset size and heterogeneity, and their calculation demands relatively less computing time and memory than other robust methods, enabling the processing of large datasets (>10^5 cells). You need to provide the names of cell types and marker genes for them. You can either enter them in the respective parameter fields (separate gene sets for different cell types with sep), or provide a .tsv file containing two columns. The first column should be for cell types, and the second for gene sets. The first is reserved for names e.g. "celltype" and "genes". Example below:

Celltype Genes
T cells CD3D, CD3E, IL7R
B cells MS4A1, CD79A, CD79B
NK cells NKG7, GNLY, PRF1

You can also input negative marker genes by postfixing them with a "-" (e.g., "CD3D-", "CD3E-"). You can also postfix the positive marker genes with a "+", like this:

Celltype Genes
T cells CD3D+, CD3E+, IL7R+, MS4A1-, CD19-
B cells MS4A1+, CD79A+, CD79B+, CD3D-, CD3E-
NK cells NKG7+, GNLY+, PRF1+, CD3D-, CD3E-, CD19-

For more details, please check:
UCell article: UCell: Robust and scalable single-cell gene signature scoring https://www.sciencedirect.com/science/article/pii/S2001037021002816

The UCell GitHub repository

Output

  • seurat_obj_ucell_annotated.Robj: The Seurat R-object to pass to the next Seurat tool, or to import to R. You cannot open this file in Chipster, but you can view the contents of the object using the Extract information from Seurat object tool.
  • Plots_UCell.pdf: UMAP of cell type scores in cells and clusters, assigned cell types per cell and cluster with labels.
