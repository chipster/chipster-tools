Seurat V5 - Identify spatially defined tissue domains with BANKSY

Description

This tool uses BANKSY (Building Aggregates with a Neighborhood Kernel and Spatial Yardstick) to incorporate neighborhood information when clustering Visium HD data.

Parameters

  • Assay to use [Spatial.008um]
  • Lambda [0.8]
  • Number of neighbours [50]
  • Resolution of granularity for clustering [0.8]
  • Number of principal components to use for clustering [30]
  • Label size of the plots [3]
  • Width of the output plot [10]
  • Height of the output plot [10]

Details

BANKSY incorporates neighborhood information for clustering by augmenting the expression pattern of a spot with both the mean and the gradient of gene expression levels in a broader neighborhood of a spot. The amount of neighborhood information incorporated is controlled by the lambda parameter, with higher values giving more weight to the neighborhood information during clustering. It is recommended to use 0.8 for domain segmentation and 0.2 for cell typing. You can define the size of the neigborhood by specifying the number of neighbors.

By incorporating neighborhood information for clustering, BANKSY is able to

  • Improve cell-type assignment in noisy data
  • Distinguish subtly different cell types stratified by microenvironment
  • Identify spatial domains sharing the same microenvironment

For more information, please check the BANKSY github repository and the BANKSY article.

Output

{assay} means the spatial assay being used e.g. Spatial.008um
