Seurat v5 -Setup and QC

Description

This tool creates a Seurat object from a tar packaged folder containing the 10x Genomics Visium HD output files. After setting up the Seurat object (.Robj), some quality control plots are drawn.

Parameters

  • Sample name [slice1]
  • Bin sizes [8, 16]

Details

This tool creates a Seurat object from a tar packaged folder containing the following 10X Genomics Visium HD output files in the following file tree hierarchy / directory structure. The tar package must have the "binned_outputs" folder at the top, with a folder for each bin size inside it, as in Space Ranger's output. You need the folders of the bin sizes you choose in the "Bin size" parameter: square_008um for 8 µm and square_016um for 16 µm. NOTE: Please make sure that the folder contains the actual files, and not just symlinks (=symbolic links) to them.

  1. binned_outputs (folder)
    1. square_008um (folder)
      1. filtered_feature_bc_matrix.h5
      2. spatial (folder)
        1. tissue_positions.parquet
        2. scalefactors_json.json
        3. tissue_hires_image.png
        4. tissue_lowres_image.png
    2. square_016um (folder)
      1. filtered_feature_bc_matrix.h5
      2. spatial (folder)
        1. tissue_positions.parquet
        2. scalefactors_json.json
        3. tissue_hires_image.png
        4. tissue_lowres_image.png

These five files are generated by the Space Ranger pipeline (more information). Make sure that you use the filtered data which contains only the tissue-associated barcodes present in your data, as opposed to the unfiltered data containing also background barcodes. Moreover, make sure the tissue_positions_list.csv does not contain the column names.

Before you run this tool, you need to make a tar package of the input files. There are graphical programs for this, such as 7-zip, or you can use command prompt (Windows) / Terminal (Mac). Go to the folder that contains the "binned_outputs" folder (Space Ranger's "outs" folder) and package only the bin sizes you need, so that the large square_002um folder is left out, for example:
tar -cvf name-for-your-package.tar binned_outputs/square_008um binned_outputs/square_016um
The Chipster tool Utilities - Make a tar package can't be used here, because it doesn't keep the folders.

If you downloaded the data as a tar package, for example a 10x Genomics example dataset, extract the whole package first and make the new tar package from the extracted folders. In these packages the image files of square_008um and square_016um are hard links to the files in square_002um, so extracting only the 8 µm and 16 µm folders leaves out the images.

If you have multiple samples, use the "Sample name" parameter to name each sample. These names are used to distinguish different samples in multiple sample analysis.

This tool also produces the following quality control plots:
  • Violin plots showing the number of UMIs (nCount_Spatial), the number of features (nFeature_Spatial), the percentage of mitochondrial reads (percent.mt), the percentage of ribosomal reads (percent.rb) and the percentage of hemoglobin reads (percent.hb) in the spots. These plots can be useful for estimating the upper/lower limits for the percentage of mitochondrial, ribosomal and hemoglobin transcripts in the filtering tool Seurat v5 -Filter spots.
  • Spatial feature plot showing the number of UMIs, the number of features and the percentages of mitochondrial and hemoglobin reads in the spots on the tissue section.
  • Box plot of the top expressed genes.

Please note that it might be easier to view the large QCplots.pdf file with an external browser window.

For more details on the Seurat Visium HD analysis pipeline, please check the Seurat tutorial.

Output

  • seurat_spatial_setup.Robj: The Seurat R-object to pass to the next Seurat tool, or to import into R. You cannot open this file in Chipster but you can view the contents of the object using the Seurat v5 -Extract information from Seurat object tool.
  • QC_plots.pdf: Quality control plots
