+		SingleR computes the Spearman correlation between cell's expression profile and that of each reference sample. The use of Spearman’s correlation provides a measure of robustness to batch effects across datasets. 
+		The per-label score is defined as a fixed quantile (0.8) of the correlations across all samples with that label. 
+		This accounts for differences in the number of reference samples for each label, and avoids penalizing classifications to heterogeneous labels by only requiring a good match to a minority of samples.
+		The score calculation is repeated for all labels in the reference dataset, and the label with the highest score is used as SingleR’s prediction for this cell.
+		In addition, a fine-tuning step is performed to improve resolution between closely related labels. 
+		The reference dataset is subsetted to only include labels with scores close to the maximum; scores are recomputed using only marker genes for the subset of labels, and this process is iterated until only one label remains.
+	</p>
